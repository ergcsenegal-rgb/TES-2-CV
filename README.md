## 🛠️ Personnalisation Simple

Tous les emplacements à personnaliser contiennent des commentaires HTML clairs :

- **Remplacer les images :** Les images sont situées dans `./assets/images/` (`students-hero.jpg` et `director-portrait.jpg`).
- **Modifier les tarifs :** Modifiez les attributs `data-monthly` et `data-annual` sur les éléments `.price-val` dans la section `#tarifs`.
- **Changer le numéro WhatsApp :** Recherchez `221766297742` dans [index.html](file:///c:/Users/USER/Desktop/TES%202%20CV/index.html) pour mettre à jour votre numéro de service client.
- **Ajouter vos vrais logos partenaires :** Remplacez les cartes de logos dans la section `<!-- 3. BANDE DE LOGOS -->`.
